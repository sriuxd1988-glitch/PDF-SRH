Key Architecture Additions in v2

🎨 Nuvexa Premium Design System (Phase 00)

  • Look and feel based on Nuvexa: Violet #864FFE, Near-Black #1A1A1C, Lime #C6F56F, Inter Tight
  • Primary buttons strictly feature pure white text (#FFFFFF) for WCAG AA compliance
  • NextSaaS rolling text buttons (.btn-v6) and lateral arrow slide pills
  • Split-screen login and signup modelled on AI Awaaz, plus admin 2FA

⚡ Direct-to-Storage Presigned Uploads

  • Client uploads directly to MinIO S3 via presigned PUT URLs, preserving VPS CPU/RAM
  • Zero Node.js buffer lag on heavy files (up to 2GB Pro)
  • Server-Sent Events (SSE) stream real-time progress to the browser
  • Strict automated S3 retention auto-deletion (1h guest / 2h free / 24h Pro)

🛡️ 100% Permissive Open-Source PDF Engines

  • Strictly zero AGPL tools (PyMuPDF and Ghostscript eliminated to protect commercial IP)
  • Powered by pypdfium2 (Google PDFium, Apache 2.0 / BSD), pikepdf (MPL 2.0), qpdf (Apache 2.0)
  • Headless LibreOffice Office conversions constrained by concurrency semaphore (limit = 1)
  • OCRmyPDF + Tesseract for searchable PDF/A generation

🧩 Website Builders & Live Design Studio in Admin

  • Header, Footer, Notification Bar, Homepage, Pages, Blog, and Ads builders
  • Live Design Studio: adjust primary/secondary colors, radius, and fonts with instant real-time propagation to the frontend
  • Full user and billing management: Razorpay Subscriptions (INR) and Stripe (USD)
  • Free users get their own dashboard with daily quota meter and auto-delete countdown
